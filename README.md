Superstore ETL Pipeline Using Python and MySQL

Developed an end-to-end ETL (Extract, Transform, Load) pipeline using Python, Pandas, and MySQL to process Superstore sales data. Extracted data from a CSV file, performed data-quality checks to identify missing values and duplicate records, converted date columns into appropriate formats, and loaded the cleaned dataset into a MySQL database using SQLAlchemy and PyMySQL.

Verified the successful data transfer through SQL queries in MySQL Workbench. This project demonstrates practical skills in data extraction, data cleaning, database connectivity, and data integration, providing a foundation for further SQL analysis and Power BI dashboard development.

Technologies: Python, Pandas, SQLAlchemy, PyMySQL, MySQL, MySQL Workbench, Git, GitHub.

Outcome: Successfully automated the CSV-to-MySQL data loading process and prepared the Superstore dataset for business analysis and visualization.
